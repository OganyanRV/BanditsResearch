# BanditsResearch — описание проекта

## Какую задачу решаем
Проект решает задачу **оффлайн- и онлайн-оценки и сравнения контекстных бандитных политик** для сценария показа баннеров/рекомендаций.

Ключевая цель — научиться корректно сравнивать алгоритмы выбора действия:
- как в симуляции (on-policy / pseudo-online),
- так и на логах (off-policy) через IPS/SNIPS,
- с детальной аналитикой по действиям и устойчивостью оценок через bootstrap.

## Что хотели сделать
Изначально цель была:
1. Разбить монолитный модуль на понятные компоненты.
2. Добавить IPS/SNIPS оценку с вероятностями выбора действия (`get_action_proba`).
3. Добавить расширяемые tree/custom-tree политики Thompson Sampling.
4. Сделать удобный workflow в CLI и ноутбуке для экспериментов и сравнения гиперпараметров.

## Что сделали
### 1) Архитектурный рефакторинг
Код разделён на модули:
- `src/bandit_benchmark_basic.py` — базовые сущности и простые политики.
- `src/bandit_benchmark_eval.py` — сценарии, evaluation loops, IPS/SNIPS метрики.
- `src/bandit_benchmark_tree.py` — sklearn-tree Thompson policy и update-стратегии.
- `src/bandit_benchmark_custom_tree.py` — кастомное дерево и его политики.
- `src/bandit_benchmark_linear.py` — линейные/лапласовские/нейросетевые варианты.
- `src/bandit_benchmark_external.py` — обёртки для внешних библиотек.
- `src/bandit_benchmark.py` — фасад/реэкспорт публичного API.

### 2) Off-policy оценка
Реализованы:
- `evaluate_policy_ips`,
- `run_scenarios_ips`,
- агрегаты IPS/SNIPS по действиям,
- выгрузка таблиц с метриками и статистиками по сценариям.

### 3) Tree-политики и update-стратегии
Поддержаны несколько режимов обновления:
- инкрементальные обновления,
- периодический refit,
- полный refit по истории,
- custom-tree сплиты (в т.ч. разные критерии).

### 4) Экспериментальный контур
- CLI (`src/run_benchmark.py`) запускает сценарии и сохраняет артефакты.
- Ноутбук (`notebooks/run_benchmark_demo.ipynb`) даёт интерактивный pipeline:
  - конфиг политик и сценариев,
  - off-policy запуск,
  - bootstrap оценки,
  - перебор гиперпараметров.

## Какой функционал реализован сейчас
- Подготовка train/test и запуск сценариев по политике/набору политик.
- Расчёт reward/regret и off-policy IPS/SNIPS.
- Пер-экшн отчёты (`action_ips_stats`) и экспорт CSV артефактов.
- Гибкие tree/custom-tree политики с несколькими update-режимами.
- Hyperparameter sweep в ноутбуке (в т.ч. для `TreeThompsonSamplingPolicyUpdateV3`).

## Практический результат
Проект стал:
- **модульным** (проще развивать и поддерживать),
- **экспериментальным** (удобнее сравнивать политики и гиперпараметры),
- **метрически зрелым** (оффлайн-оценка через IPS/SNIPS + bootstrap).
